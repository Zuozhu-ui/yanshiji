## v1.3 · 计时可信（最高优先级）

**目标**：锁屏、切后台、被杀进程，都敢把时间交给它。

### 1. 番茄钟到点提醒

- **现状**：到 0 只显示 `00:00`，继续计时，不提醒
- **方案**：接入 `@capacitor/local-notifications`；开始时按 `目标分钟` 计算结束时间并预约通知；到点震动 + 通知，可选「自动暂停」
- **验收**：设 1 分钟番茄 → 锁屏 → 到点收到通知并震动；回到 App 显示 00:00，状态为已暂停

### 2. 常驻通知 / 前台服务

- **现状**：锁屏后看不到「正在计时」，容易忘停
- **方案**：Android 前台服务 + 常驻通知，提供「暂停 / 结束」两个动作；通知文案显示科目与已计时长
- **技术点**：`POST_NOTIFICATIONS`（Android 13+）、`FOREGROUND_SERVICE_SPECIAL_USE`（targetSdk 36）、Capacitor 插件桥接
- **验收**：计时中通知栏常驻；点通知里的暂停立即生效；锁屏 30 分钟后回来时长准确

### 3. 恢复逻辑修正

- **现状**：杀进程后恢复，关机期间按绝对时间计入，可能虚增数小时
- **方案**：心跳里记录 `lastHeartbeatAt`；恢复时把结束点截断到 `lastHeartbeatAt + 10s`，弹窗让用户确认「算到 X 点 / 丢弃」
- **验收**：计时 5 分钟后杀进程，隔 3 小时打开 → 不会出现 +3 小时

### 4. 学习场景手感

- 屏幕常亮（计时中）：`FLAG_KEEP_SCREEN_ON` 或 keep-awake 插件
- 震动反馈：开始 / 暂停 / 保存
- Android 返回键：先关弹窗 → 再回首页 → 再按退出
- 通知权限被拒时给出可读引导

**依赖**：`@capacitor/local-notifications`、`@capacitor/haptics`、`@capacitor/app`，可能自写前台服务插件
**预估**：5–7 天（含真机调试）

## v1.4 · 回顾有用

**目标**：让「看统计」真的能指导下一步，而不是只看总数。

### 1. 周期对比

- 本周 vs 上周：总时长、日均、次数、各科目变化
- 本月 vs 上月
- 展示形式：指标卡右下角 `↑ 2h` / `↓ 30m`

### 2. 科目目标

- 每科可设「每周目标时长」（可选）
- 统计页显示完成度进度条；首页提示「本周还差 X 小时」

### 3. 自动周报

- 每周一生成一段文字总结：总时长、最投入科目、连续天数、与上周对比
- 可选：生成一张可分享的图片（纯前端 canvas，不上传）

### 4. 日志检索

- 关键词搜索（内容 / 科目）
- 按科目筛选
- 按月折叠分组

### 5. 复盘可见化

- 复盘从「选择某一天」里解放出来：首页/日志顶部显示「今天的一句话」
- 新增复盘列表（按日期倒序）

### 6. 时间分布

- 上午 / 下午 / 晚上 / 深夜 的时长分布
- 回答「我什么时候效率最高」

**验收**：能在 10 秒内回答「这周比上周怎么样、哪科欠账、我什么时候效率高」
**预估**：3–4 天

## v1.5 · 一眼开始 & 存储升级

### 1. 桌面小组件（Android AppWidget）

- 显示今日时长 + 连续天数 + 「开始专注」按钮
- 点击直接进入计时页（可带科目参数）
- 技术点：AppWidgetProvider + 原生插件读取 localStorage 数据（或写入 SharedPreferences 镜像）

### 2. 长按图标快捷方式

- 静态 shortcuts：「开始专注」「补录一条」
- 成本低，可先做

### 3. 继续上次

- 首页显示「继续 · 阅读」，一键开始
- 记住上次科目

### 4. 补录增强

- 支持起止时间（可选切换），而不只是时长
- 「复制上一条」快速补录

### 5. 存储升级

- localStorage → IndexedDB（保留一次性迁移 + 旧数据兼容读）
- 分片写入，避免整表重写
- 突破 5MB 上限

### 6. 可选：应用锁

- 4 位 PIN / 生物识别，保护学习记录隐私

**预估**：5–8 天（小组件与存储是两块大头）

## 候选池（未排期）

- CSV 导出（给 Excel 用）

## 明确不做

| 功能 | 原因 |
|---|---|
| 云同步 / 账号 | 与「纯本地、安静」定位冲突，且需要服务器与隐私合规 |
| 社交 / 排行榜 | 会把工具变成压力源 |
| 任务管理 / 笔记系统 | 失焦，最后两头都不好用 |
| 半成品番茄钟 | 要么完整（提醒 + 自动切换），要么去掉 |

## 发布检查清单

每次发版逐项确认：

1. `app/package.json` 与 `build.gradle` 版本号一致、`versionCode` 递增
2. 构建 `dist-capacitor`（`--base=/ --outDir=dist-capacitor`），确认产物包含本次改动
3. `npx cap sync android`
4. `gradlew assembleRelease`（JDK 21）
5. `apksigner verify --print-certs` 确认签名未变
6. 单元测试 `npm test` 全绿
7. 真机走一遍「安装 → 计时 → 保存 → 导出 → 导入」
8. 写 Release 说明（用户视角），上传 APK
9. 更新 `CHANGELOG.md`
